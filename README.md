# DmC Dubba Testing

Multi-project QA management platform for game dubbing/mod testing.

This repository will contain:

- Tester desktop client
- Admin/developer desktop client
- Backend API
- Shared contracts and domain models
- Hugging Face storage integration
- Build, task, bug, retest, notification and analytics workflows

> Initial project: DmC: Devil May Cry Turkish Dub QA
